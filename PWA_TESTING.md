# Проверка PWA на GitHub Pages

## 🔍 Как проверить что PWA работает:

### 1. Откройте сайт

- Перейдите на https://robocotik.github.io/RIP_Toeing_Frontend/
- Подождите полной загрузки страницы

### 2. Проверьте в Chrome DevTools

- Откройте DevTools (F12)
- Перейдите на вкладку **Application**
- Проверьте разделы:
  - **Manifest**: должен показать все иконки и настройки
  - **Service Workers**: должен быть зарегистрирован sw.js
  - **Storage > Cache Storage**: должен содержать кэш с файлами

### 3. Проверьте установку PWA

- В адресной строке Chrome должна появиться иконка установки (⊕ или стрелка)
- Нажмите на неё
- Выберите "Установить"
- Приложение должно открыться в отдельном окне

### 4. Проверьте офлайн режим

- В DevTools перейдите в **Network**
- Поставьте галочку **Offline**
- Обновите страницу
- Приложение должно работать офлайн

### 5. Отладочная информация

- Добавьте `?debug=1` к URL для просмотра статуса PWA
- Например: https://robocotik.github.io/RIP_Toeing_Frontend/?debug=1

## ✅ Что исправлено для работы PWA:

1. **Корректные пути в manifest**

   - scope: '/RIP_Toeing_Frontend/'
   - start_url: '/RIP_Toeing_Frontend/'

2. **Правильные пути к изображениям**

   - Использование import.meta.env.BASE_URL
   - Все SVG сохранены локально в /images/rumbs/

3. **Service Worker конфигурация**

   - Кэширование статических ресурсов
   - Правильные glob patterns
   - Runtime caching для изображений румбов

4. **GitHub Pages настройки**

   - .nojekyll файл для корректной работы
   - Правильный base URL в vite.config.ts

5. **Отладочные компоненты**
   - PWADebug для диагностики
   - PWAInstallPrompt для установки
   - NetworkStatus для статуса сети

## 🚨 Возможные проблемы:

1. **HTTPS обязателен** - PWA работает только по HTTPS (GitHub Pages это обеспечивает)
2. **Service Worker регистрация** - должна происходить после загрузки страницы
3. **Manifest валидность** - все поля должны быть корректными
4. **Иконки** - должны быть доступны по указанным путям

## 📱 Тестирование на мобильных:

1. **Android Chrome**:

   - Появится банер "Добавить на главный экран"
   - Или в меню браузера "Добавить на главный экран"

2. **iOS Safari**:
   - В меню Safari выберите "Добавить на экран Домой"

После установки приложение будет работать как нативное!
