# Разработка интернет-приложений (РИП) 2025

Тема: Время полета Boeing-737 NG между Лондоном и Парижем в зависимости от направления ветра.
Цель работы заключается в разработке системы, включающей в себя основной веб-сервис, дополнительный асинхронный сервис на Django, веб-приложение и нативное приложение на Tauri, которая позволит пилотам создавать заявки на расчет длительности полета, а диспетчерам – управлять каталогом направлений ветра и обрабатывать заявки.
