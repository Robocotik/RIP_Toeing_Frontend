# Инструкции по настройке GitHub Pages

## Шаги для активации GitHub Pages:

1. **Откройте настройки репозитория**

   - Перейдите в ваш репозиторий на GitHub
   - Нажмите на вкладку "Settings"

2. **Найдите раздел "Pages"**

   - В левом меню найдите "Pages"
   - Нажмите на него

3. **Настройте источник**

   - В разделе "Source" выберите "GitHub Actions"
   - Это позволит использовать наш workflow файл

4. **Проверьте права доступа**

   - Убедитесь что в Settings > Actions > General включено "Allow all actions and reusable workflows"
   - В разделе "Workflow permissions" выберите "Read and write permissions"

5. **Запустите деплой**
   - Сделайте push в ветку `ReactPWA`
   - GitHub Actions автоматически соберет и задеployит сайт
   - Сайт будет доступен по адресу: `https://robocotik.github.io/RIP_Toeing_Frontend/`

## Проверка PWA функциональности:

После деплоя на GitHub Pages:

1. Откройте сайт в Chrome/Edge
2. В адресной строке появится иконка установки
3. Нажмите на неё чтобы установить PWA
4. Приложение появится в меню устройства
5. Работает офлайн после первого посещения
